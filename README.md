# Life OS

Личная система для всей жизни: дела, время, деньги, здоровье, цели, заметки — в одном приложении.
Сделано с учётом СДВГ: мысль записывается за 3–5 секунд, минимум трения, понятный экран дня, приятный отклик.

- Работает в браузере и как приложение на iPhone (PWA, «На экран „Домой“»), офлайн.
- Данные хранятся **на устройстве** (IndexedDB); по желанию — зашифрованная синхронизация через ваш бесплатный Supabase. В репозитории нет личных данных и ключей.
- Стиль «Glassy»: тёмная стеклянная тема по умолчанию, светлая и «как в системе».

**Адрес приложения** (после включения GitHub Pages): `https://saidsharifov09.github.io/LIFE-OS/`

## Как устроено

```
src/
  db/           схема IndexedDB (Dexie) и типы данных
  actions/      слой действий: addTask, completeTask, capture, processInbox, addEvent, getDay… (с отменой)
  lib/          даты, разбор фраз (parse.ts), категории, форматирование
  ui/           дизайн-система: карточки, кнопки, поля, прогресс, шторка, тосты, конфетти
  app/          оболочка (навигация), тема, список разделов
  sync/         облачная синхронизация: клиент Supabase, движок, автосинхронизация
  modules/      разделы: home, capture, inbox, tasks, calendar, review, settings, design, …
docs/           SPEC, DATA, DECISIONS, NOTIFICATIONS, AI, WIDGET, SUPABASE (подключение облака)
supabase/       schema.sql — таблицы и правила доступа для облака
.github/        сборка и публикация на GitHub Pages
```

Каждый раздел — отдельная папка в `src/modules`. Все изменения данных — только через `src/actions`
(см. [docs/AI.md](docs/AI.md)).

## Разработка (в облаке, на ноутбуке ничего ставить не нужно)

```
npm ci          # зависимости
npm run dev     # локальный сервер
npm test        # модульные тесты (Vitest)
npm run build   # сборка в dist/
```

Публикация происходит автоматически: каждый пуш в `main` → GitHub Actions → GitHub Pages.

## Как установить на iPhone

1. Откройте адрес приложения в **Safari**.
2. «Поделиться» → «На экран „Домой“» → «Добавить».
3. Открывайте с экрана «Домой» — без адресной строки, работает без интернета.

## Резервная копия (раз в неделю)

Настройки → «Резервная копия» → «Сохранить копию в iCloud» → в окне «Поделиться» выберите «Сохранить в Файлы» → iCloud Drive.
По желанию включите «Зашифровать паролем» (забудете пароль — копию не открыть).
Восстановить: Настройки → «Восстановить из файла» → «Объединить» или «Заменить».
