# Настройка с iPhone: облачный ИИ, уведомления, Face ID

Всё делается в Safari на iPhone, без компьютера и командной строки. Займёт 15–20 минут один раз.
Ключи и пароли **никуда не пересылайте** (ни в чат, ни в GitHub) — только туда, куда сказано в шагах.

Нужно заранее: подключённое облако Supabase в Life OS (Настройки → Облако). Если ещё нет — сначала [SUPABASE.md](SUPABASE.md).

---

## Шаг 1. Обновить приложение

1. Откройте https://github.com/saidsharifov09/LIFE-OS/pulls → откройте последний Pull Request → **Merge pull request** → **Confirm merge**.
2. Подождите 3 минуты. Откройте Life OS — в **Настройках** появятся карточки «Помощник» и «Уведомления».

## Шаг 2. Важно: открывайте Life OS с экрана «Домой»

Уведомления на iPhone приходят только приложению, добавленному на экран «Домой».

1. Откройте https://saidsharifov09.github.io/LIFE-OS/ в **Safari**.
2. Кнопка **«Поделиться»** (квадрат со стрелкой) → **«На экран „Домой“»** → **«Добавить»**.
3. Дальше открывайте Life OS **только с иконки**.

> У иконки на экране «Домой» своя память, отдельная от Safari. Если облако вы подключали в Safari — в приложении с иконки
> подключите его ещё раз (Настройки → Облако: тот же адрес, ключ, email и пароль шифрования). Данные подтянутся из облака.

## Шаг 3. Бесплатный ключ ИИ (Groq, без карты)

1. Откройте https://console.groq.com/keys и войдите (Google или email).
2. **Create API Key** → имя `lifeos` → **Submit**.
3. Нажмите **Copy**. Ключ показывается один раз — если потеряли, просто создайте новый.

## Шаг 4. Функция `life-os` в Supabase (одна на ИИ и уведомления)

1. В Life OS: **Настройки → Уведомления → «Код функции»** — код скопирован.
2. Откройте https://supabase.com/dashboard/project/_/functions (если спросит — выберите свой проект).
3. **Deploy a new function** → **Via Editor**.
4. Имя функции: `life-os` (ровно так, маленькими буквами).
5. В редакторе выделите весь пример и удалите, затем вставьте скопированный код → **Deploy function**.
6. Откройте функцию `life-os` → **Details** (или **Settings**) → выключите **Verify JWT** (Enforce JWT verification) → **Save**.
   Функция сама проверяет, что это вы.

## Шаг 5. Ключ Groq — в секреты функции

1. Откройте https://supabase.com/dashboard/project/_/functions/secrets
2. **Add new secret**: Name — `GROQ_API_KEY`, Value — ключ из шага 3 → **Save**.
3. *По желанию:* ещё один секрет `ALLOWED_EMAILS` = ваш email. Тогда функцией не сможет пользоваться никто, кроме вас.

## Шаг 6. Будильник уведомлений (SQL)

1. В Life OS: **Настройки → Уведомления → «SQL для уведомлений»** — скопирован (адрес вашего проекта уже внутри).
2. Откройте https://supabase.com/dashboard/project/_/sql/new
3. Вставьте и нажмите **Run**. Должно быть **Success** (ошибок красным нет). Повторный запуск ничего не ломает.

## Шаг 7. Включить уведомления

1. Life OS (с иконки) → **Настройки → Уведомления → «Включить уведомления»** → **«Разрешить»**.
2. Нажмите **«Прислать тест»** — через пару секунд придёт «Уведомления работают ✓».
3. Готово: события (за сколько минут — в самом событии) и задачи со временем будут приходить, даже когда приложение закрыто.

По умолчанию в уведомлении нет названия дела («⏰ Задача на 15:00») — так названия не хранятся на сервере.
Хотите видеть названия — включите **«Показывать названия дел»** (тогда они хранятся в Supabase без шифрования).

## Шаг 8. Включить облачный ИИ в помощнике

**Настройки → Помощник → «Облачный ИИ» → «Понимаю, включить» → «Проверить»**. Должно быть «Облачный ИИ отвечает ✓».

## Шаг 9. Face ID

1. **Настройки → PIN-код → «Включить PIN»** (если ещё нет) — придумайте 4–6 цифр.
2. Включите **«Входить по Face ID»** → подтвердите лицом.
3. Теперь при открытии Life OS сам появится Face ID. Не получилось — введите PIN, как раньше.

В «Пароли» iPhone появится ключ входа «Life OS» — это он, не удаляйте.

## Если что-то не так

| Что видите | Что сделать |
|---|---|
| «Сначала подключите облако» / «Войдите в облако» | Настройки → Облако (в приложении с иконки — отдельно, см. шаг 2) |
| «В Supabase нет функции life-os» | Шаг 4: имя ровно `life-os`, нажата **Deploy** |
| «Нужно войти» при правильном входе | Шаг 4, пункт 6: выключить Verify JWT |
| «Нет таблиц уведомлений — выполните SQL» | Шаг 6 |
| «В секретах функции нет ключа ИИ» | Шаг 5 |
| «Бесплатный лимит закончился» | Подождите (лимит Groq — в минуту и в сутки) или добавьте второй ключ: `GEMINI_API_KEY` / `OPENROUTER_API_KEY` |
| Тест не приходит | iPhone: Настройки → Уведомления → Life OS → «Допуск уведомлений» включён; режим «Не беспокоить» выключен; нажмите «Включить заново» |
| Нет переключателя Face ID | Сначала включите PIN; Face ID должен быть настроен в самом iPhone |

Что и куда уходит: в Groq — только текст фразы помощнику и дата. В Supabase для уведомлений — время напоминаний
(и названия, только если вы их включили). Остальные данные в облаке зашифрованы вашим паролем.
