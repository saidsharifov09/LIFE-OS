# Облако Life OS: Supabase за 10 минут (с iPhone)

Облако нужно, чтобы данные были одинаковыми на iPhone и ноутбуке и не пропали, если телефон потеряется.
Всё бесплатно, карта не нужна. Данные шифруются **на устройстве** паролем синхронизации ещё до отправки:
в Supabase лежит только шифр, прочитать его без вашего пароля нельзя (ни Supabase, ни кому-то ещё).

> Ничего из этого не нужно вставлять в код или в чат. Адрес и публичный ключ вводятся прямо в приложении
> (Настройки → «Облако и синхронизация») и хранятся только на устройстве.

## Шаг 1. Аккаунт
1. Откройте в Safari **supabase.com** → **Start your project**.
2. Нажмите **Continue with GitHub** (тот же аккаунт GitHub) → разрешите доступ.

## Шаг 2. Проект
1. **New project** (если спросят организацию — создайте любую, тариф **Free**).
2. Name: `life-os`. Database Password: нажмите **Generate a password** (этот пароль приложению не нужен — можно
   сохранить в «Пароли» iPhone на всякий случай). Region: **Frankfurt (eu-central-1)** — ближе всего.
3. **Create new project** и подождите 1–2 минуты, пока проект создаётся.

## Шаг 3. Таблицы (один раз скопировать и вставить)
1. Откройте файл схемы: <https://github.com/saidsharifov09/LIFE-OS/blob/main/supabase/schema.sql>
   → кнопка **Raw** → выделите весь текст → «Скопировать».
2. В Supabase слева **SQL Editor** (значок `>_`) → **New query** → вставьте текст → **Run**.
   Должно появиться «Success. No rows returned». Запускать повторно можно — ничего не сломается.

Схема создаёт таблицы `records` (зашифрованные записи) и `vault` (соль и проверка пароля) и включает
**Row Level Security**: каждый пользователь видит только свои строки.

## Шаг 4. Адрес сайта (и, по желанию, код в письме)
1. **Authentication → URL Configuration**: Site URL = `https://saidsharifov09.github.io/LIFE-OS/` → **Save**.
2. **Authentication → Sign In / Providers → Email**: должно быть включено (Enabled) — обычно так по умолчанию.
3. *По желанию.* **Authentication → Emails** → шаблоны **Magic Link** и **Confirm signup** → **Source** → добавить в конец
   `<p>Код для входа в Life OS: <b>{{ .Token }}</b></p>` → **Save changes**. Тогда в письме будет 6-значный код.
   Если Supabase не даёт менять шаблоны (на бесплатной почте так бывает) — пропустите: войти можно и по ссылке.

**Как входить по ссылке на iPhone:** в письме **не нажимайте** «Sign in» / «Confirm your mail» (ссылка откроется
в Safari, а не в приложении на экране «Домой»), а **удерживайте палец** на ней → «Скопировать ссылку» →
вставьте в поле «Код или ссылка из письма» в Life OS → «Войти».

> Бесплатная почта Supabase отправляет письма только на адрес **владельца проекта** (тот, что в аккаунте Supabase /
> GitHub) и не чаще нескольких раз в час. Для личного приложения этого достаточно — входите с этим же email.

## Шаг 5. Адрес и ключ → в приложение
1. В Supabase: **Project Settings** (шестерёнка) → **Data API** (или **API**) → скопируйте **Project URL**
   (вида `https://abcd1234.supabase.co`).
2. **Project Settings → API Keys**: скопируйте публичный ключ — **anon public** (длинный, начинается с `eyJ…`)
   или **publishable** (`sb_publishable_…`). **Не** копируйте `service_role` / `secret` — он не нужен и его нельзя
   никуда вставлять.
3. В Life OS: **Настройки → Облако и синхронизация** → вставьте адрес и ключ → **Подключить**.
4. Введите email → **Получить код** → вставьте код или скопированную ссылку из письма → **Войти**.
5. Придумайте **пароль синхронизации** (минимум 8 символов) и сохраните его в «Пароли» iPhone.
   **Забудете — данные в облаке не восстановить** (на устройствах они останутся).

## Шаг 6. Ноутбук
Откройте Life OS на ноутбуке → Настройки → те же адрес и ключ → тот же email и код → тот же пароль синхронизации.
Через несколько секунд всё появится. Индикатор «Синхронизировано» — в боковой панели и на главной.

## Как это работает
- Основная база — на устройстве, приложение работает без интернета. Изменения отправляются через ~3 секунды,
  новое из облака подтягивается при запуске, при возвращении в приложение и раз в минуту.
- Конфликт (правили одно и то же на двух устройствах): побеждает **более новая** правка.
- Удаление тоже синхронизируется (в корзину — как правка, окончательное удаление — как «надгробие»).
- «Выйти» на устройстве не удаляет данные на нём. «Забыли пароль?» — очищает облако, после чего можно задать новый
  пароль и загрузить данные с этого устройства.
- Бесплатный проект Supabase засыпает после 7 дней **без запросов**. При ежедневном пользовании этого не случится;
  если уснул — в supabase.com нажмите **Restore project**.

## Если Supabase недоступен (запасной вариант, тоже бесплатно)
Если supabase.co не открывается из вашей сети, можно ходить к нему через свой адрес на Cloudflare Workers
(бесплатно, 100 000 запросов в день):

1. **dash.cloudflare.com** → зарегистрироваться → **Workers & Pages** → **Create** → **Create Worker** → **Deploy**.
2. **Edit code** → замените весь код на текст ниже (подставьте свой Project URL) → **Deploy**:
   ```js
   const SUPABASE = 'https://abcd1234.supabase.co'; // ваш Project URL
   export default {
     async fetch(req) {
       const u = new URL(req.url);
       return fetch(new Request(SUPABASE + u.pathname + u.search, req));
     },
   };
   ```
3. В Life OS вместо адреса Supabase вставьте адрес воркера (`https://….workers.dev`). Ключ — тот же.

Шифрование при этом не меняется: воркер видит только шифр. Самый последний запасной вариант без облака —
файл резервной копии (Настройки → «Резервная копия»), его можно переносить через iCloud Drive или Telegram.
