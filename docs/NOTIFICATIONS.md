# Напоминания и уведомления

## Как сейчас (честно)

У Life OS нет сервера. Поэтому **iPhone не может показать уведомление по расписанию, когда приложение закрыто**.
Это ограничение веб-приложений: таймеры работают только пока страница открыта, а push-уведомления
приходят только от сервера.

Что сделано:

1. **Напоминания внутри приложения** (`src/modules/calendar/reminders.ts`). Пока Life OS открыт, раз в 30 секунд
   проверяются события (за N минут до начала, N задаётся в событии) и задачи со временем. Показывается тост,
   а если разрешены системные уведомления (Настройки → «Разрешить») — ещё и уведомление.
   Уже показанные напоминания запоминаются, чтобы не повторяться.
2. **«В Календарь iPhone»** (Этап 4, `src/lib/ics.ts`, `src/ui/IcsButton.tsx`): кнопка в задаче (если есть дата),
   событии и регулярном платеже. Можно выбрать несколько напоминаний (VALARM): для дел со временем — «в момент»,
   «за 5/15/30 мин», «за 1–2 часа», «за день»; для дел на весь день (платежи, дни рождения) — «в день, 9:00»,
   «накануне, 19:00», «за день», «за 3 дня», «за неделю». Повторы переносятся как RRULE.
   Календарь iPhone сам напомнит в нужный момент — это **самый надёжный бесплатный способ** для важных дел,
   платежей и дней рождения. Дни рождения (`birthdayItem`) подключатся к разделу «Люди» на Этапе 6.
   Ограничение: это копия — если перенести дело в Life OS, в календаре оно не изменится (добавьте заново).

## Push при закрытом приложении (сделано, бесплатно)

С iOS 16.4 Safari поддерживает Web Push для приложений **на экране «Домой»**. Настройка — [SETUP-IPHONE.md](SETUP-IPHONE.md), шаги 2, 4, 6, 7.

Как устроено:
1. **Подписка** (`src/modules/notify/push.ts`): «Включить уведомления» → разрешение → `pushManager.subscribe` с публичным
   ключом VAPID → подписка сохраняется в `push_subscriptions` через функцию `life-os`.
2. **Расписание** (`src/lib/pushPlan.ts`): те же напоминания, что внутри приложения (события за N минут, задачи со временем),
   на **14 дней вперёд**, до 300 штук. Отправляется целиком при включении, после изменений задач/событий (через 4 с),
   при возвращении в приложение и не реже раза в 6 часов. Сервер заменяет все неотправленные; уже отправленные не повторяются.
   Если не открывать приложение больше 14 дней — дальнейшие напоминания не придут, пока не откроете.
3. **Будильник**: `pg_cron` раз в минуту вызывает функцию (`action: push-tick`, секрет в `push_config`). Функция атомарно
   «забирает» созревшие напоминания (помечает отправленными) и шлёт Web Push. Опоздавшие больше чем на час не шлёт.
4. **Отправка** (`supabase/functions/life-os/index.ts`): шифрование RFC 8291 (aes128gcm) и подпись VAPID (ES256) на встроенном
   WebCrypto, без библиотек. Ключи VAPID функция создаёт сама и хранит в `push_config`. Подписка, на которую push-сервис
   ответил 404/410, удаляется.
5. **Сервис-воркер** (`public/push-sw.js`, подключён через `importScripts`): показывает уведомление, по нажатию открывает
   нужную запись (`#/tasks?open=…`, `#/calendar?date=…&open=…`).
6. **Приватность**: по умолчанию на сервер уходит только время и «⏰ Задача на 15:00». Названия — только если включить
   «Показывать названия дел» (тогда они лежат в Supabase без шифрования). Таблицы закрыты RLS без разрешений —
   читает и пишет только функция ключом сервиса и только записи вошедшего пользователя.
7. Пока приложение открыто, работают и внутренние напоминания (тост); системное уведомление при включённом push
   присылает только сервер — без дублей.
