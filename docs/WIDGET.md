# Виджет на экране iPhone

**Нативный виджет (WidgetKit) без Mac не собрать**: нужен Xcode, а он есть только на macOS.
Кроме того, веб-приложение (PWA) не может создавать виджеты iOS.

Варианты:

1. **Ярлык PWA на экране «Домой»** (есть уже сейчас): Safari → «Поделиться» → «На экран „Домой“».
   Открывается как отдельное приложение, сразу на «Мой день».
2. **Приложение «Команды» (Shortcuts)** — бесплатно, без Mac:
   - команда «Открыть URL» `https://<ваш-логин>.github.io/LIFE-OS/#/` — быстрый запуск;
   - можно поставить команду на экран «Домой» как значок или вызывать через Siri;
   - виджет «Команды» на экране «Домой» показывает кнопки команд (например, «Быстрая запись»
     → откроет приложение; адрес с параметром захвата можно добавить на Этапе 8).
3. **Виджет «Календарь» iPhone**: задачи и события, добавленные через «Добавить в Календарь iPhone» (.ics, Этап 4),
   появятся в стандартном виджете календаря.
4. **Сторонние приложения-виджеты** (Scriptable и аналоги) могут показывать данные по ссылке/JSON —
   возможно после облачной синхронизации (Этап 4.5), но данные зашифрованы, поэтому потребуется
   отдельный «открытый» срез (например, только число задач на сегодня). Решать по запросу.
5. **Нативное приложение** — только с Mac (или арендой облачного Mac) и платным аккаунтом разработчика
   для постоянной установки. Не входит в планы.
